## ✨ Features

- 🤖 **AI Gift Assistant** — Smart filter-based gift recommendations (Occasion, Budget, Age, Gender, Relationship)
- 🛍️ **Gift Catalog** — Browse curated premium gifts with filters & search
- 🛒 **Shopping Cart & Checkout** — Full cart and order management
- 📱 **WhatsApp Notifications** — Auto order tracking via Twilio WhatsApp
- 🔊 **Voice Input** — English, Hindi & Telugu voice commands
- 🌙 **Dark Mode** — Beautiful dark/light theme switching
- 🔑 **Auth System** — Login, Register, User Dashboard

---

## 🏗️ Tech Stack

| Layer | Technology |
|:---|:---|
| **Frontend** | Next.js 16, React 19, TailwindCSS 4, Framer Motion |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB Atlas (with local JSON fallback) |
| **AI** | Rule-based engine + OpenAI GPT-4o-mini (optional) |
| **Notifications** | Twilio WhatsApp API |
| **Deployment** | Vercel (frontend) + Render (backend) |
